# Continuous Audit Election Infrastructure

A design proposal for watching a voter roll and a paper count while they change. Not an official election system.

The pages are the explanation. The reason they are split, and how to run them, is in [docs/site.md](docs/site.md). Current work is in [docs/RECENTGOALS.md](docs/RECENTGOALS.md).

Claims and the sources behind them are rendered at `/receipts`. The list lives in `src/content/receipts.ts`.
